# 鹈鹕岛 · 骑向海风

精致的 Canvas 2D 自行车冒险小游戏。无运行时依赖，所有角色、风景、粒子和音乐均由代码生成。

[进入游戏](https://pelican-island-ride-linyang.yanglinchasel.chatgpt.site)（托管入口沿用当前站点的访问设置；源码可独立运行。）

[GitHub 源码仓库](https://github.com/LinYangBIT/pelican-island-ride)

## 本地运行

需要 Python 3。在项目目录运行 `python3 -m http.server 8793 --bind 127.0.0.1 --directory dist`，然后访问 `http://127.0.0.1:8793`。也可以用 Node 18+ 执行 `npm run dev`。无需安装依赖或构建，不要直接双击 HTML（浏览器模块需要 HTTP 服务）。

验证源码使用 `npm run check`，机制与音频生命周期测试使用 `npm test`。这些自动检查是浏览器试玩的补充，不是音质或真机性能证明。

## 玩法

- 海盐公路：平缓起伏，后半程顺风加速，适合冲刺收集。
- 翡翠雨林：更明显的丘陵、原木障碍和更多跳板，考验起跳节奏。
- 星夜灯塔：较轻的重力、更多上升气流和高空珍珠，适合滑翔。
- 岛屿冒险：完成 1200 米。无尽漫游：每 900 米切换景色，挑战个人纪录。
- 自动前进；空格 / ↑ / W 跳跃，再按二段跳，长按在下降时滑翔。
- Shift / → / D 冲刺，↓ / S 减速，P / Esc 暂停。
- 手机使用屏幕下方的跳跃、冲刺、刹车按钮；跳跃支持长按滑翔。
- 鱼干连击每 8 个提高一次倍率，最高 4 倍；珍珠结算为 5 鱼干。
- 磁铁吸引附近收集物；护盾抵挡碰撞；跳板和气流帮助跃过障碍。
- 每次骑行有收集、起跳、冲刺三项任务，每项奖励 20 鱼干。
- 每 400 米补给站自动恢复 1 点生命和 35 能量（冒险终点不重复补给）；跳过金环额外奖励 10 鱼干。
- 腾空至少 0.28 秒、成功越过障碍后落地，奖励 3 鱼干与 8 能量。提前按下的跳跃可在落地前 140 毫秒缓存。
- 每条路线保留最高星级和最佳通关用时。旧版本的钱包、装备、静音和纪录继续保留。
- 工坊可升级速度、吸附范围和初始护盾，各有 3 级，费用为 60 / 140 / 260 鱼干。
- 设置、余额、升级和个人纪录保存在当前浏览器的 localStorage。更换浏览器不会同步。

## 造型与光影升级（v1.2）

保留 Canvas 2D 海岛插画风，以分层曲面、材质渐变和定向高光增强立体感；不是 WebGL 3D 或光线追踪。自行车增加透明轮辐、轮胎与金属轮圈、管状车架、传动链条及同步脚踏。角色加入层叠羽毛、喙囊明暗、头盔通风口和织物/皮革细节。场景增加塔楼结构、岩层、树冠、远景空气透视、碎裂水面反光与随高度变化的接触投影；夜航使用冷色月光。

轻量档保留主轮廓和材质，减少辐条、缝线、波纹与粒子。`tools/visual-qa.html` 可在项目根目录启动 HTTP 服务后打开，用固定时间/视角检查新旧造型与光照开关。15 秒采集区分浏览器帧间隔和 Canvas 同步提交耗时，不代表独立 GPU 耗时或真机性能。

## 文件

- `dist/index.html`：页面、菜单、操作界面。
- `dist/style.css`：响应式布局和视觉样式。
- `dist/game.js`：游戏循环、物理、关卡、输入、音效与存档。
- `dist/renderer.js`：画布绘制、动画、可收集道具与效果。
- `dist/cyclist-model.js`：鹈鹕与自行车的分层造型、材质和动作。
- `dist/island-scenery.js`：海岛、植被、建筑和水面光影。
- `dist/terrain-model.js`：道路、障碍物和地面投影。
- `dist/routes.js`：路线参数、连续地形与路段节奏。
- `dist/audio.js`：原创 16 小节配乐与音频生命周期。
- `tests/`：游戏机制与音频生命周期回归检查。
- `.openai/hosting.json`：仅在 Sites 工作副本保留的部署配置，公开源码导出无需此文件。

## 操作体验

游戏离开当前窗口会自动暂停。BGM 默认开启：页面尝试播放，浏览器阻止时在首次有效操作后自动播放。菜单、骑行、暂停和结算采用不同层次，音乐与音效有独立音量和总静音；后台停止调度，不积压补播。声音偏好保存在当前浏览器。

设置中的「轻量画面」降低分辨率、粒子和部分装饰；系统减少动态效果偏好会作为首次默认值。手机、平板按触控能力显示按钮，支持横屏。浏览器尺寸模拟不代表 iOS / Android 真机音频和帧率验证。
