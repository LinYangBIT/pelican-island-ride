# v1.2 视觉验收 · 2026-11-14

## 实现边界

沿用 Canvas 2D，以分层轮廓、明暗渐变和解析投影表达体积。没有引入 WebGL、3D 网格、光线追踪或外部素材。主光为画面右上；接触投影向左，骑手离地时投影变宽、变淡。月夜改用冷色材质，保留障碍辨识。

## 视觉和交互

- 固定 t=5、1366×768 视口，对照 v1.1 造型与 v1.2，并单独切换新版光照/反光。轮辐透景，金属、橡胶、皮革和羽毛有不同明暗；修复了水面高光的硬边梯形。
- 检查海岸近景、月夜滑翔及雨林正常骑行。菜单和实际游玩使用相同造型模块。
- 通过键盘实际完成星夜灯塔 1200 米：45.2 秒，3 次漂亮落地，最长连击 40；没有直接改写游戏状态。
- 390×844 与 844×390 浏览器视口检查：雨林菜单、轻量画面、屏幕跳跃/滑翔/冲刺、暂停与重开。无控件遮挡，保留轻量档主轮廓。
- 浏览器控制台 warning/error 列表为空。语法、机制与音频测试通过；绘制烟测覆盖 288 个尺寸/场景/状态/姿势/画质/光照组合，数值有限且 Canvas 状态栈平衡。

## 绘制采样

macOS Codex 内置浏览器；视口 1366×768，Canvas 1366×583，DPR=1。同一雨林骑行夹具、相同初始时刻，各持续动画 15 秒。夹具不执行游戏物理；“CPU”只计同步 Canvas 提交，“帧间隔”包含浏览器调度，均不是独立 GPU 计时。

| 路径 | 样本 | 帧间隔 P50/P95 (ms) | 大于33.3ms | CPU P50/P95 (ms) |
| --- | ---: | ---: | ---: | ---: |
| v1.1 原版 | 816 | 16.8 / 25.3 | 0 | 0.6 / 1.0 |
| v1.2 完整 | 874 | 16.7 / 25.2 | 0 | 1.4 / 2.3 |
| v1.2 轻量 | 849 | 16.7 / 25.2 | 0 | 1.0 / 1.6 |

新增细节提高了绘制提交成本；该采样未出现超过33.3ms的长帧。轻量档减少水面条带、树叶微细节、羽毛缝线与辐条，降低提交成本。样本之间的调度差异不能当作新版加速的证据。

未覆盖 iOS/Android 真机、GPU 计时或电量测试。音频未改动，不重复声称新的主观音质验收。

运行夹具：在项目根启动 `python3 -m http.server 8793 --bind 127.0.0.1`，访问 `/tools/visual-qa.html`；实际游戏为 `/dist/`。常规 `npm run dev` 只服务 `dist/`，不会发布验收工具。
